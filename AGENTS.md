# Repository guidance

## UI writing

**Brevity is the soul of width.**

- Keep interface copy short, direct, and scannable.
- Prefer a clear label or one sentence over explanatory paragraphs.
- Put optional detail behind a tooltip, disclosure, or debug view.
- Do not write essays in sidebars, dialogs, status messages, or inspector panels.
- Preserve the user's working area: text must earn the width and height it occupies.
